## 作業系統到底是什麼？

你今天大概用過電腦或手機。你點擊東西、看影片，也許還打了什麼字——一切都*順順地運作*。但你有沒有想過，幕後究竟是什麼在掌控一切？

那個看不見的層，就叫做**作業系統（operating system）**，縮寫為 **OS**。

這樣想吧：電腦的硬體——螢幕、鍵盤、記憶體、處理器——就像汽車的車身。零件一應俱全，但光靠零件，車子不知道怎麼*行駛*。作業系統就像引擎管理系統加上儀表板控制器的結合體：讓一切運作起來，並給你一種與它互動的方式。

更具體地說，作業系統有三項主要工作：

1. **管理硬體**——它直接與你的 CPU、RAM、儲存裝置及其他元件溝通，讓應用程式不必自己處理這些事。每個應用程式只要問 OS：「嘿，我需要一些記憶體」或「請儲存這個檔案」，OS 就會把繁瑣的工作搞定。
2. **執行程式**——當你雙擊一個應用程式，OS 就會載入它、給它資源，並讓它持續運行。OS 還會確保多個應用程式能同時共用電腦而不互相干擾。
3. **提供使用者介面（UI）**——桌面、工作列、檔案總管、視窗——這些全都是 OS 的一部分。這是你看到並點擊的東西。

沒有 OS，你的電腦只是一堆昂貴的矽和塑膠，按下電源鍵什麼也不會發生。

## 常見的作業系統

### Windows

**製造商：** Microsoft  
**首次發布：** 1985 年  
**目前最常見的版本：** Windows 11

Windows 是全球使用最廣泛的桌面作業系統，遠勝其他對手。如果你曾用過學校的電腦、圖書館的電腦或家用 PC，很可能就是 Windows。

#### Windows 的辨識特徵

- **開始功能表**——位於左下角（或 Windows 11 中央）的那個按鈕，開啟所有應用程式的啟動器。
- **工作列**——底部那條顯示已開啟應用程式和系統匣的列。
- **檔案總管**——用來瀏覽檔案和資料夾的應用程式。

#### 為什麼人們使用 Windows？

- **廣泛的軟體相容性**——幾乎所有軟體都能在 Windows 上執行，包括遊戲、創意工具、商業應用程式等。
- **廣泛的硬體支援**——Windows 可在數百個不同製造商的筆電和桌機上執行：Dell、HP、ASUS、Lenovo 等。
- **大多數人都熟悉**——因為太普及，大多數人早就知道怎麼用了。

#### 有什麼缺點？

Windows 有時被批評為，若不妥善維護，更容易受到病毒侵害；而且它可能會堆滿你從未要求安裝的預載應用程式。它也需要授權（儘管大多數 PC 已內含授權）。

### macOS

**製造商：** Apple  
**首次發布：** 2001 年  
**目前最常見的版本：** macOS Sequoia（2024）

macOS 是 Apple Mac 電腦上執行的作業系統——MacBook、Mac Mini、iMac 桌機和 Mac Studio。它以簡潔精緻的設計和與 Apple 生態系的緊密整合而聞名。

#### macOS 的辨識特徵

- **Dock**——位於螢幕底部（或側邊）的一排應用程式圖示，隨時觸手可及。
- **選單列**——螢幕最頂端那條細長的列，會依據你正在使用的應用程式而改變。
- **Spotlight 搜尋**——按 `⌘ 空白鍵`，搜尋列就會彈出。你可以啟動應用程式、搜尋檔案、做計算等——完全不需要碰滑鼠。

#### 為什麼人們使用 macOS？

- **流暢的設計**——macOS 以外觀和手感精緻而聞名。動畫流暢、字型清晰，整體感覺很有質感。
- **適合創意工作**——影片剪輯師、音樂人、設計師和開發者往往喜愛 Mac。Final Cut Pro 和 Logic Pro 等應用程式是 macOS 獨有的。
- **Apple 生態系**——如果你也有 iPhone 或 iPad，Mac 能與它們無縫協作。你可以在 Mac 上接聽 iPhone 來電，在手機上複製某個東西然後貼到筆電，等等。
- **底層基於 Unix**——macOS 建立在 Unix 基礎上，這讓它在欣賞強大終端機的開發者之間很受歡迎。

#### 有什麼缺點？

macOS 只能在 Apple 硬體上執行，而 Apple 硬體通常比同等規格的 Windows 機器貴。你也較難自訂系統，因為 Apple 對使用體驗有嚴格管控。

### Linux

**製造商：** 開源社群（最初由 Linus Torvalds 於 1991 年發起）  
**最常見的版本（稱為「發行版」）：** Ubuntu、Fedora、Debian、Arch Linux

Linux 與 Windows 和 macOS 有一個根本上的不同：它是**開源（open source）**的。這意味著任何人都可以查看它的程式碼、修改並重新發布——完全免費。因此，Linux 有很多不同風味，稱為**發行版（distributions）**，或簡稱「distro」，各有不同的外觀、感覺和用途。

#### Linux 的辨識特徵

這是棘手之處——Linux 沒有一個固定的外觀。有些發行版看起來像 Windows，有些像 macOS，有些則完全獨特。共同點是 Linux 讓你對系統有更多控制權。

大多數 Linux 發行版都有：
- **桌面環境**（如 GNOME 或 KDE Plasma），決定視覺風格。
- **終端機（terminal）**——控制電腦的文字方式，Linux 使用者傾向大量使用。
- **套件管理器（package manager）**——類似內建應用程式商店的工具，可從命令列安裝軟體。

#### 為什麼人們使用 Linux？

- **免費**——永遠不需要支付授權費。
- **高度可自訂**——你幾乎可以讓它呈現任何你想要的外觀和行為。
- **輕量**——一些 Linux 發行版可以在很舊的硬體上流暢執行，而這些硬體在 Windows 或 macOS 上會吃力。
- **開發者和工程師的最愛**——大多數網路伺服器、雲端系統和超級電腦都執行 Linux。早點學習它是很大的職涯優勢。
- **隱私友好**——Linux 不像 Windows 或 macOS 那樣收集你的資料。

#### 有什麼缺點？

Linux 有較陡的學習曲線。一些熱門軟體（如 Microsoft Office 或 Adobe Photoshop）不官方支援 Linux，雖然有替代方案。如果你只想要「開箱即用」的東西，Windows 或 macOS 可能更容易上手。

## 三者比較

| | Windows | macOS | Linux |
|---|---|---|---|
| **費用** | 付費（通常隨機附贈） | 付費（需要 Apple 硬體） | 免費 |
| **硬體** | 任何 PC | 僅限 Apple | 任何 PC |
| **自訂性** | 有限 | 非常有限 | 廣泛 |
| **軟體相容性** | 最廣 | 良好 | 因版本而異 |
| **最適合** | 遊戲、一般使用 | 創意工作、Apple 用戶 | 開發者、注重隱私的用戶 |
| **開源？** | 否 | 否 | 是 |


## 等等——你的手機也有 OS

這可能會讓你驚訝：每支智慧型手機也有作業系統。你一直在使用它，卻沒有特別去想——而這正是重點。行動作業系統被設計成讓你幾乎感覺不到它的存在。

### Android

**製造商：** Google  
**搭載於：** Samsung、Google Pixel、OnePlus、Xiaomi 以及大多數其他 Android 手機

Android 是全球使用最多的行動 OS。它基於 Linux（是真的！）且核心是開源的，這就是為什麼這麼多不同的手機製造商可以使用和自訂它。Samsung 的「One UI」例如，只是 Android 穿上了 Samsung 自己風格的外衣。

每次你向下滑通知、開啟應用程式抽屜，或從 Google Play 商店安裝東西時，你就在使用 Android。

### iOS

**製造商：** Apple  
**搭載於：** iPhone 和 iPod Touch

iOS 是 Apple 的行動作業系統，和 macOS 一樣，它只限於 Apple 硬體。它以非常流暢、安全，以及與 Apple 生態系的緊密整合而聞名。

每次你點選主畫面按鈕、在應用程式間滑動，或在 iPhone 上開啟 App Store，你就在使用 iOS。

### 為什麼人們對行動 OS 感受不那麼強烈？

在桌面上，OS 非常明顯——你能看到桌面、工作列、檔案系統。在手機上，體驗被設計成感覺更像是一串應用程式，而不是「電腦」。OS 把自己隱藏起來。但它仍然在做同樣的基本工作：管理硬體、執行應用程式，並給你一個介面。

## 摘要

**作業系統（operating system）**是讓電腦可用的軟體。它夾在硬體和使用者之間，管理資源並提供互動介面。

- **Windows**——最常見的桌面 OS，非常適合遊戲和一般使用。
- **macOS**——Apple 精緻的 OS，深受創意工作者和開發者喜愛。
- **Linux**——免費、開源的 OS，極度靈活，並驅動了大部分的網際網路。
- **Android**——使用最廣泛的行動 OS，基於 Linux，運行在大多數智慧型手機上。
- **iOS**——Apple 的行動 OS，專屬於 iPhone，以流暢和安全著稱。

每次你開啟裝置，OS 是第一個甦醒的——在任何應用程式之前，在你的桌布之前，在一切之前。它是其他一切建立其上的基礎。
