夜明けに気温センサーが 10°C を示し、正午に 24°C を示したとする。気温が連続的に変化していたなら、その途中のどこかで必ず 17°C を通過したはずだ。中間値定理（Intermediate Value Theorem）はこの日常的な観察を厳密に定式化し、値を明示的に計算しなくても零点や不動点の存在を証明する道具にする。

## 定理の主張

**定理（中間値定理、IVT）。** $f : [a, b] \to \mathbb{R}$ を[連続](../continuous/)関数とする。$y$ が $f(a)$ と $f(b)$ の間の任意の値であれば、$f(c) = y$ を満たす $c \in (a, b)$ が存在する。

実用上便利な言い換え：$f(a)$ と $f(b)$ が**異符号**（すなわち $f(a) \cdot f(b) < 0$）であれば、$f$ は $(a, b)$ 内に零点を持つ。

## 二分法による証明

一般性を失わず $f(a) < y < f(b)$ と仮定する。

**二分法**により区間 $[a_n, b_n]$ の列を $[a_0, b_0] = [a, b]$ から次のように帰納的に定める：

- 中点 $m_n \coloneqq \dfrac{a_n + b_n}{2}$ を取る。
- $f(m_n) < y$ なら $[a_{n+1}, b_{n+1}] \coloneqq [m_n, b_n]$ とする。
- $f(m_n) \geq y$ なら $[a_{n+1}, b_{n+1}] \coloneqq [a_n, m_n]$ とする。

構成より各ステップで $f(a_n) < y \leq f(b_n)$ が成り立ち、区間の幅は

$$
b_n - a_n = \frac{b - a}{2^n} \;\to\; 0
$$

と減少する。

$\mathbb{R}$ の**完備性**（縮小区間の共通部分は一点）により、$c \in \bigcap_{n=0}^{\infty} [a_n, b_n]$ となる点 $c$ が一意に定まる。

$a_n \leq c \leq b_n$ かつ $b_n - a_n \to 0$ より $a_n \to c$ かつ $b_n \to c$。$f$ の連続性から $f(a_n) \to f(c)$ および $f(b_n) \to f(c)$。すべての $n$ で $f(a_n) < y$ だから $f(c) \leq y$。すべての $n$ で $f(b_n) \geq y$ だから $f(c) \geq y$。したがって $f(c) = y$。$\square$

## 応用

### 多項式の零点

奇数次の実多項式はかならず実数の零点を持つ。次数 $2k+1$ の多項式 $p$ は $x \to +\infty$ で $+\infty$ に、$x \to -\infty$ で $-\infty$ に発散するので、十分大きい $R > 0$ に対して $p(-R) < 0 < p(R)$ となる。IVT より $(-R, R)$ 内に零点が存在する。

**例。** $p(x) = x^3 - 2$ は連続で $p(0) = -2 < 0$、$p(2) = 6 > 0$ を満たす。IVT より $c^3 = 2$ となる $c \in (0, 2)$ が存在する——これが $\sqrt[3]{2}$ の存在証明だ。

### 不動点の存在

**系（1 次元の Brouwer の不動点定理）。** 任意の連続関数 $f : [0, 1] \to [0, 1]$ は**不動点**を持つ：$f(c) = c$ となる $c \in [0, 1]$ が存在する。

*証明。* $g(x) \coloneqq f(x) - x$ とおく。$f$ は $[0,1]$ を $[0,1]$ に写すので $g(0) = f(0) \geq 0$、$g(1) = f(1) - 1 \leq 0$。いずれかが $0$ なら $0$ または $1$ が不動点。そうでなければ $g(0) > 0 > g(1)$ となり、IVT より $g(c) = 0$、すなわち $f(c) = c$ となる $c \in (0, 1)$ が存在する。$\square$

### 二分法アルゴリズム

証明は構成的だ。各ステップで零点を含む区間を半分にするので、$n$ ステップ後には根の位置を $(b - a)/2^n$ の精度で特定できる。これが**二分法（bisection method）**であり、確実に線形収束する最も信頼性の高い零点探索アルゴリズムの一つだ。

```python
def bisect(f, a, b, tol=1e-9):
    assert f(a) * f(b) < 0, "f must have opposite signs at a and b"
    while (b - a) / 2 > tol:
        m = (a + b) / 2
        if f(m) == 0:
            return m
        elif f(a) * f(m) < 0:
            b = m
        else:
            a = m
    return (a + b) / 2
```

## まとめ

- **中間値定理**：$[a, b]$ 上の[連続](../continuous/)関数 $f$ は $f(a)$ と $f(b)$ の間のすべての値を取る。
- **証明**：各ステップで端点が異符号を保つよう区間を二分する。$\mathbb{R}$ の完備性が交点を確定し、連続性がその点での値を $y$ に等しくさせる。
- **零点探索**：奇数次多項式はかならず実数の零点を持つ。$x^3 - 2$ への適用が $\sqrt[3]{2}$ の存在を示す具体例だ。
- **不動点**：$[0, 1]$ から $[0, 1]$ への連続写像はかならず不動点を持つ——$f(x) - x$ に IVT を適用して証明する。
- **二分法**：証明はアルゴリズムでもある。$n$ ステップで精度 $\varepsilon$ を得るのに $O(\log(1/\varepsilon))$ 回の評価で足りる。
