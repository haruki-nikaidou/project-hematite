**直積型（product type）**は複数の値を1つにまとめる。Rustの直積型には3つの形式がある：名前付きフィールドの構造体、タプル構造体、そしてタプルだ。

## 名前付きフィールドの構造体

最も一般的な直積型は名前付きフィールドの構造体（struct）だ：

```rust
struct Point {
    x: f64,
    y: f64,
}
```

値を作成するには、各フィールドを列挙する：

```rust
let p = Point { x: 3.0, y: 4.0 };
```

フィールドを読むには `.` を使う：

```rust
let distance = (p.x * p.x + p.y * p.y).sqrt();
```

構造体は**名前的型付け（nominally typed）**だ：同じフィールド型を持つが名前が異なる2つの構造体は別の型だ。`Point` と `Size { width: f64, height: f64 }` は、どちらも2つの `f64` 値を保持していても、互換性がない。

## 構造体更新構文

既存の構造体をほとんどコピーした新しい構造体を作成するときは `..` を使う：

```rust
let p2 = Point { x: 1.0, ..p }; // p2.y は p.y からコピーされる
```

明示的にリストされたフィールドはその値を取り、`..base` は残りすべてを `base` から補完する。

## タプル構造体

**タプル構造体（tuple struct）**は型に名前を付けるが、フィールドへのアクセスは位置で行う：

```rust
struct Color(u8, u8, u8);

let red = Color(255, 0, 0);
println!("{} {} {}", red.0, red.1, red.2);
```

タプル構造体は、フィールドに名前を付けても明確さが増さないが、同じ形状の他のタプルと型を区別したい場合に便利だ。`Color` と `Point3D(f64, f64, f64)` は、どちらも3つのコンポーネントを持っていても混同されない。

## ユニット構造体

**ユニット構造体（unit struct）**はデータを持たない：

```rust
struct Marker;

let m = Marker;
```

ユニット構造体はゼロサイズだ。型レベルのトークンとして使われる — トレイト実装を持ち運んだり、ファントム型パラメータとして使ったりする。

## タプル

匿名の直積型が**タプル（tuple）**だ：

```rust
let pair: (i32, bool) = (42, true);
let (n, flag) = pair;  // デストラクチャリング
let n2 = pair.0;       // インデックスアクセス
```

タプルは名前付き構造体を定義せずに関数から2つか3つの値を返すときに便利だ。より大きなものや意味のあるものには名前付き構造体を使うのが好ましい。

## デストラクチャリング

すべての直積型は `let` バインディングで**デストラクチャリング（destructuring）**をサポートする：

```rust
let Point { x, y } = p;
println!("{x}, {y}");
```

関数パラメータでも：

```rust
fn translate(Point { x, y }: Point, dx: f64, dy: f64) -> Point {
    Point { x: x + dx, y: y + dy }
}
```

デストラクチャリングは、`p.x`、`p.y`… と繰り返し書かずに複数のフィールドを同時に扱いたいときのイディオムだ。

## なぜ「直積」か

直積型の値の数は、そのフィールドの値の数の*積*だ。`bool` が2つの値を持ち `u8` が256個の値を持つなら、`(bool, u8)` は $2 \times 256 = 512$ 個の可能な値を持つ — 各組み合わせに1つだ。この乗算関係が名前の由来だ。

## `impl` による振る舞いの追加

構造体は `impl` ブロックを通じてメソッドを得る：

```rust
impl Point {
    fn distance_from_origin(&self) -> f64 {
        (self.x * self.x + self.y * self.y).sqrt()
    }
}

let p = Point { x: 3.0, y: 4.0 };
println!("{}", p.distance_from_origin()); // 5
```

`&self` は所有権を取らずにレシーバを借用する。メソッドは特定の型に振る舞いを付与する手段だ；トレイトはこれを多くの型にまたがる共有の振る舞いへと一般化する。
